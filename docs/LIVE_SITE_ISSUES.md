# Live-site issues found while building the Solutions and industry pages

Found on beyondbancard.com on 21 Sept 2026, while copying the live content into the top 6 industries and every Solutions page (D-058). These are problems on the **current live site**. The demo does not repeat them: each is handled as described in D-058, and anything unconfirmed is flagged in `docs/CONFIRM_LIST.md`.
